# V2 收盘研究模型实现

日期：2026-09-17。版本：`accumulation-v2.0-experimental`。

本轮按用户要求暂不使用 13F 验证。已实现独立的分钟特征、跨日评分、状态机、真实缓存回测与原始行情重放。该版本供收盘研究，尚未校准识别效果；Web 控制台与自动监测仍运行 v1，v1 的规则哈希与历史回放保持不变。

## 已实现范围

- 四个基础证据族：交易方向代理 30、下行冲击与恢复 25、相对价格保持 20、跨日连续性 25。
- 5/10/20 日窗口固定权重 0.25/0.50/0.25；背景样本结束日早于当前窗口起点，回归仅使用先前日线。
- 支撑恢复与放量不再是所有证据的共同前置条件。构造的正常成交量、连续温和正向样本可以形成候选。
- 缺失字段保留未知区间，不重分配权重；缺少逐笔不改变基础分。观察、候选、增强、衰减、失效与关闭独立于 v1 保存。
- 逐笔模块目前验证合格双流下的主动方向，给出 supports/contradicts/inconclusive/unavailable；历史 bars 不补造逐笔，也未在本轮启动持续双流采集。
- 原始行情只归档一次，每日特征只归档一次，检查点引用特征哈希；支持从原始行情重新计算特征和全部状态。
- 回测不查询持仓披露，不修改生产数据库，不创建邮件投递；研究事件的 notifiable 始终为 false。

默认阈值 65 是事先选定的实验值，不代表 65% 概率，也没有利用 GOOG 结果校准。命令可显式指定设计允许的阈值集合，每个配置有独立 manifest 哈希；不自动搜索最佳阈值。

## 运行

在项目目录的 PowerShell 中，使用已核验的历史缓存：

```powershell
.\.venv\Scripts\python.exe -m accuflow.cli backtest --model v2 --symbol GOOG --start 2025-09-15 --end 2026-09-15 --cache data/backtests/goog/history.db --review data/backtests/goog/review.json --output data/backtests/goog/my-v2-run
```

输出目录必须不存在。需要从已经登录的 Gateway 补数时追加 `--download --host 127.0.0.1 --port 4002 --client-id 71`。下载只写有 backtest 标记的独立缓存；禁止拿业务数据库当下载缓存。

计划依据特征依赖生成 226 个交易日的分钟预热范围，并另需可用的先前日线回归样本。质量与样本数逐日检查，日期数量达到计划不代表数据自动合格。早期缓存只有 v1 所需历史时，v2 会如实输出不可评分日期。输出状态 needs_review 的退出码为 2，报告仍保留；不能把它当作全年无信号。

完整重放：

```powershell
.\.venv\Scripts\python.exe -m accuflow.cli replay-v2 --input data/backtests/goog/my-v2-run
```

该命令核对归档校验和，从原始行情重建每日特征，再逐个检查预测与状态连续性。只接受当前受支持的代码/参数哈希，不静默用修改后的模型重放旧结果。

原有 `backtest` 不加 `--model` 时仍是 v1；`--threshold` 只能用于 v2。

## 输出

| 文件 | 内容 |
|---|---|
| manifest.json | 参数、实验状态、代码与配置哈希 |
| inputs.json.gz | 原始行情、会话、核验记录和运行配置 |
| features.jsonl.gz | 每日连续特征、质量、系数、承接事件与哈希 |
| snapshots.jsonl.gz | 每个检查点的特征引用、先前状态和完整计算结果 |
| daily.json / daily.csv | 目标区间逐日状态、评分上下界、质量、首次候选及价格表现 |
| summary.json / report-zh.md | 覆盖率、候选数量、后续价格表现与解释边界 |
| replay-verification.json | 完整重放通过后生成的复算结果 |

价格表现从信号日之后下一交易日开盘开始，统计 5/10/20 日价格收益、相对 SPY 的差值及有利/不利幅度。未完成的未来区间右删失，不使用信号当天收盘作为可以即时成交的价格；不含分红、费用和滑点，不等于策略收益。

## 实现约定

- 日级方向值使用历史分位数，D 只累积连续证据，不读取过去是否报警。
- 原始指标等于常数背景时处于中位，无异常贡献；首次偏离常数背景可在百分位上体现，不用 MAD 除以零。
- 承接使用历史相邻时段、相近量能事件匹配；缺少匹配样本标不可用，后续 30 分钟未完成的事件保持 pending。
- 反证在各自历史背景中归一，分数区间同时考虑未知的正向贡献与未知扣分。
- 同日重复调用不增加天数、不重复发候选。缺失日保留状态；证据覆盖模式变化时不把分数落差解释为衰减。
- 逐笔支持要求当前完整会话、同长度历史会话，以及最近五个实际交易日内的方向持续；不能跨断档拼接五个“有数据的日子”。
- 收盘研究快照使用当前下载的数据版本，明确为 historical_reconstruction。严格截断未来事件不等于恢复当年的真实数据到达时序。

## 测试与后续范围

新增测试覆盖正常量能连续需求、未来数据隔离、持仓数据不参与评分、事后事件隔离、未知分数范围、同日幂等、数据缺口、逐笔分布与跨日缺口、失效条件、序列化确定性、原始行情重建、归档篡改和专用缓存边界。

后续仍需：多股票行情对照、阈值校准、实际持续双流采集、盘中同检查点基线、发行人层提醒去重、Web/API 的 v2 选择与报告展示。13F 研究按本轮要求暂缓，不构成本次代码实现的前置条件。

完整工程与真实行情结果见 [2026-09-17 验收记录](validation/v2-implementation-20260917.md)：87 项测试、478 个原始行情重建检查点通过；252 个目标日均可评分。
